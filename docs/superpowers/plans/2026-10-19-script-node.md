# 目标与依据

依据 `../output/libtv-script-research/实测记录.md` 和两份完整三步实测，新增独立 `script` 节点，不以旧版 LLM 分镜预设替代。保留 Banana 主题、已有图像/视频模型和服务端计费。LibTV 批量视频不再实际调用，使用已有视频生成链路实现。

# 开发顺序与验收

1. **领域协议与后端**：脚本镜头、角色/场景/道具使用稳定 ID；独立 SQL 文档及异步任务表；乐观版本锁、租户/画布权限、任务幂等、取消、失败恢复。验证非法结构/重复 ID/悬空引用/跨租户访问/重复结算。
2. **独立 LLM 配置**：租户高级配置新增“脚本”；启用、默认模型、多模型、Base URL、API Key、OpenAI Chat/Responses、火山方舟 Responses；密钥掩码保留、测试连接。剧本生成与智能合成分别按配置的每次积分成功结算，自动拼接免费。验证配置脱敏、接口调用参数及错误脱敏。
3. **节点与三步编辑器**：空态三个入口；连接文本/图像、补充要求、模型、生成/取消/重试；确认镜头表（对白多条、景别、光影、音效、运镜、时长、引用、排序、色标、增删）；资产分类、风格、上传/画布/个人资产库/AI生成、保存资产/清图/跳转；最终图像与视频双提示词、选择镜头、智能合成/免费自动拼接、重新合成。每次编辑立即写库，冲突可见。
4. **媒体批处理**：选择条目、编辑 prompt、现有模型参数及费用、仅缺项重试；生成独立画布节点并关联脚本/编组，保留任务 ID；批量分镜与视频遵守三步完成门槛，视频采用分镜图为首帧。逐项提交避免对标站并发超限问题，成功项保留。
5. **导出与验收**：UTF-8 BOM CSV 分镜表+资产表，含双提示词；自动测试、前后端构建、浏览器完成手工创建→三步→导出及高级配置验证。真实上游模型调用仅在已配置可用模型时验证，否则明确记录限制。

# 持久化与边界

- `canvas_script_documents` 是脚本编辑真源，版本控制避免多人覆盖；画布节点存概览。
- `canvas_script_tasks` 持久化异步 LLM 工作，worker 租约和心跳、请求唯一键、节点单活动任务；结果写库与积分扣除在同一事务。
- 图片/视频请求只调用原有 `/api/images/generate`、`/api/videos/generate`，不添加第二套媒体计费。
- 各项失败显示具体状态，已成功资产/镜头不重跑；自动补全设定须明确标记；长剧本禁止静默省略集数和关键对白。
- 本次继续现有四仓库 `dev`；不改超管无关功能，不自动部署生产。
