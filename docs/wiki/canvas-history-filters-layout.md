# 画布历史记录与资产筛选栏布局

- [历史记录面板](../../src/components/canvas/HistoryPanel.vue)将空间、媒体分类和搜索放在同一筛选区域。
- 全屏宽屏使用单行布局，搜索框填充剩余宽度；搜索框与分类标签统一为 32px 高，让下方媒体列表获得更多高度。
- 480px 侧栏及宽度不超过 900px 的全屏视口使用两行：首行放空间和搜索，次行放分类，避免控件过度压缩。
- [资产面板](../../src/components/canvas/AssetPanel.vue)放大后也将空间、分类和搜索放入同一筛选区域，搜索框与分类标签统一为 32px 高；视口至少 1600px 时单行展示，较窄视口改为两行。普通资产侧栏维持原有排布。
- 分类筛选、角色库菜单和搜索逻辑保持原有行为。
